AI Copilot

Ask in plain English. The copilot picks tools (SQL, vector search, compute, LLM, actions), runs them, and answers only from what they return. Pick a question to replay it.

Conversation

Hi. I can query customer data, search tickets and call notes, explain scores, draft outreach and set up alerts. Try one of the questions on the right.

Try asking

Mock: answers are pre-written, tool calls are shown as the real copilot would log them. Maximum 5 tool turns per question.

Data needed: structured tables (SQL) plus unstructured text for the vector store: ticket threads, CSM call notes, QBR notes, outreach emails, NPS comments. The generator needs to write realistic free text for these, tied to each customer's story arc.
